# jinlang-office-fahuo

一个用于办公场景的发货管理与提醒小工具。

目前项目主要用于整理销售/发货数据，并为后续自动统计、客户脱敏、发货周期分析和提醒功能做准备。

## 计划功能

- 导入 Excel 销售/发货数据
- 统计订单总量、已发货量和剩余量
- 根据历史记录估算发货周期
- 对客户名称、产品型号等敏感信息进行本地脱敏
- 生成适合 AI 分析的脱敏数据
- 根据规则或 AI 判断需要跟进的客户
- 支持 Windows / 企业微信 / QQ 等提醒方式

## 项目状态

项目目前处于早期开发阶段，功能和目录结构可能会持续调整。

## 目标

尽量让敏感业务数据保留在本地，仅将脱敏后的数据用于统计或 AI 分析，在减少人工整理工作的同时降低信息泄露风险。
